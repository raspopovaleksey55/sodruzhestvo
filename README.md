# Сайт ОРОО «ЦКПП «Содружество»

Статический сайт организации: семь страниц, один файл стилей, без внешних библиотек
и чужих скриптов. Публикуется на GitHub Pages прямо из этого репозитория.

**Адрес сайта:** https://raspopovaleksey55.github.io/sodruzhestvo/

## Страницы

| Файл | Что на странице |
|---|---|
| `index.html` | Главная: чем занимаемся, организация вкратце, проекты, приглашение к сотрудничеству |
| `o-nas.html` | О нас: цели и предмет деятельности по уставу, история, краткие сведения |
| `proekt-zakat-imperiy.html` | Проект «Что такое неоколониализм: образ Африки на закате империй» |
| `issledovaniya.html` | Исследования: шесть докладов на конференциях, три публикации |
| `komanda.html` | Команда: руководство и исследовательская работа |
| `dokumenty.html` | Документы и реквизиты, органы управления |
| `kontakty.html` | Контакты и с чем к нам обращаться |
| `style.css` | Оформление всех страниц |
| `img/` | Изображения (пока пусто) |

## Как обновлять

Файлы правятся на компьютере, изменение фиксируется коммитом — через минуту-другую
GitHub Pages публикует новую версию. Ничего компилировать не нужно.

**Что стоит добавить:**

- **Логотип** — когда появится, положить в `img/logo.png`; сейчас в шапке стоит текстовый знак «С».
- **Фотографии** — в `img`, снимки с мероприятий и с выставки.
- **Годовые отчёты** — в папку `otchety` под именами `otchet-2025.pdf` и так далее;
  после этого на странице «Документы» появятся ссылки на скачивание.
- **Раздел «Новости»** — когда начнутся мероприятия; обновляемый сайт ценится выше
  застывшего.

## Публикация

- Источник: ветка `main`, корень репозитория.
- Файл `.nojekyll` отключает обработку сайта через Jekyll — страницы отдаются как есть.
- Свой домен подключается позже: файл `CNAME` с именем домена плюс записи в DNS
  у регистратора; сертификат HTTPS на GitHub Pages выдаётся бесплатно.
  Свободные варианты: `sodruzhestvo55.ru`, `sodruzhestvo-omsk.ru`.
